MADE BY AGENTS

Your agent builds the rest.

Ask your coding agent for what you want: "show my open PRs in the notch", "a pomodoro beside the camera". The island redraws within a second of a save.

  1. READS

    One guide, the exact API

    ~/.config/opennook/AGENTS.md explains mods, layout and themes; nook.d.ts and ui.d.ts are the API, word for word.

  2. WRITES

    A folder of JavaScript

    Run programs, fetch URLs, follow log files, read what's playing or which agents are working. A broken edit never breaks the island: the last good version keeps running.

  3. CHECKS

    And looks before it's done

    opennook check loads the mod against live data and reports every problem; opennook shot renders the island to a picture the agent can look at.

mods/battery/main.js 
import { View, row, text, icon } from "nook/ui";
import { exec } from "nook";

export default class Battery extends View {
  init(props, cx) {
    const refresh = async (cx) => {
      const { stdout } = await exec("pmset", ["-g", "batt"]);
      this.percent = Number(stdout.match(/(\d+)%/)?.[1]);
      cx.notify();
    };
    cx.spawn(refresh);
    cx.timer.every(60_000, (cx) => cx.spawn(refresh));
  }

  // Closed: beside the camera, only when it's low.
  activity() {
    if (!(this.percent < 20)) return null;
    return { leading: icon("battery-low", 16).color("red"),
             trailing: text(`${this.percent}%`) };
  }

  // Open: its own page.
  expanded() {
    return row().gap(10).child(icon("battery", 18)).child(text(`${this.percent}%`));
  }
}

MAKE IT YOURS

The island itself is a file too.

Not just what's in it: its colours, its shape and which mod goes first are all in layout.json, applied live.

Themes

Default, graphite, midnight, ember, forest and rose, or your own: every mod uses the same colour tokens, so one change restyles them all.

Its look

A border, a glow, a gradient, rounder corners, Liquid Glass under the open island: for every mod at once, or from one mod while it's showing. A build that fails can turn the island red.

Everything stays local

No account, no telemetry, no cloud. Your mods are files on your Mac, rendered on the GPU by a native Rust app.
